# Network Connectivity Issue Resolution
**Date Created:** December 10, 2025  
**Last Updated:** December 10, 2025

## **Skills Demonstrated:**
- Diagnosing Layer 1–3 connectivity issues
- Using network troubleshooting tools (ping, ipconfig, tracert, arp, nslookup)
- Checking Windows network adapters and configurations
- Identifying DNS issues vs. gateway issues
- Reviewing routing tables
- Resetting network stacks (Windows + Linux)
- Using Event Viewer and logs for network errors
- Understanding how DHCP assignment, static IPs, and subnetting affect connectivity
- Validating connectivity inside a virtualized environment

## **Objective:**
- To simulate real-world helpdesk scenarios involving users who cannot access the network or internet
- To identify root causes (DHCP failure, DNS misconfiguration, gateway issues, NIC problems, etc.)
- To practice using both GUI and CLI tools to diagnose and resolve connectivity issues
- To build repeatable troubleshooting workflows that match what Tier 1–2 helpdesk roles expect

## **Tools & Environment:**
- Linux Host running Virtual Machine Manager (KVM/QEMU)
- Windows 11 Client VM
- Windows Server (Domain Controller / DHCP / DNS) VM
- Tools used:
    -Windows CMD tools: ping, ipconfig, arp, nslookup, tracert
    -PowerShell networking commands
    -Windows Network Adapter settings (GUI)
    -Event Viewer (System / Network logs)
    -Server Manager (DHCP & DNS roles)
- Virtual networking through VMM NAT or isolated virtual network
